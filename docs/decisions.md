# 议题与决策

本文记录基础版设计的当前有效结论、尚待细化的问题和历史决策。产品与文档结构见[文档总览](README.md)，核心概念见[共同学习模型](design/learning-model.md)。

## 修改的方式

基础版的设计以 `docs/` 下的当前有效文档为依据，修改按以下方式进行。

1. 一项修改对应一个议题，以 PR 提出，同时更新相关文档及本文件中的状态。
2. 已确认结论是后续设计的依据。新增结论取代或修订旧结论时，将相应旧条目移入历史决策，并说明替代关系。
3. 设计方向的确认与详细正文、接口规格的完成分别记录。已经确认的概念可以继续展开论证、例子和使用条件；涉及目标或设计立场的变化另行提出。
4. 一项机制是否加入基础版，按设计哲学中[依据实际使用演进](design/goals-and-principles.md)的立场判断：缺少它时基础流程无法完成，或者实际使用中已经出现它要解决的问题。
5. 使用经验按其含义进入相应位置。学习者明确作出的选择与持续约定进入个人设定；对表现的观察及其条件进入记录，关于能力和教学效果的判断依据新证据修订。能够跨情境复用的经验，在明确适用条件和依据后进入学习方法。需要新增机制的，按上一项判断；其余列为暂缓事项。

现行版本（v1）的修改依据根目录 [DESIGN.md](../DESIGN.md) 中“修改系统的方式”进行。

| 事项 | 要解决的问题 | 重新考虑的条件 |
