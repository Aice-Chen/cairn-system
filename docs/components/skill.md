# 技能：模型使用的指引与参考内容

技能向模型提供辅导目标、教学判断依据、记忆的使用说明和按需参考的学习方法。产品定位见[目标与设计哲学](../design/goals-and-principles.md)，共享概念见[共同学习模型](../design/learning-model.md)，教学选择与记忆效力分别见[辅导](../design/tutoring.md)和[长期记忆](../design/memory.md)。

## 职责与组成

技能将设计内容组织为模型能够在实际辅导中使用的说明。不同内容的组织依据是用途和需要使用的时机。

| 内容 | 作用 | 使用时机 |
|---|---|---|
| 技能描述 | 说明 Cairn 适用的请求与学习情境 | 客户端选择技能时 |
| 指引正文 | 说明辅导目标、主要判断关系、决定权与记忆的使用 | 进行 Cairn 辅导时 |
| 学习方法参考 | 提供具有用途、适用条件和依据的可选教学安排 | 当前目标、困难或任务需要时 |
| 记忆格式参考 | 说明页面和记录的格式、相关写入约定 | 需要解释或写入相应内容时 |

学习方法可以按所解决的问题、任务条件和所需支持组织。具体参考内容的划分与取用方式，在相关方法细化时确定，见[议题与决策](../decisions.md)。

## 指引需要说明的内容

### 角色、目标与责任

模型担任长期学习辅导者，依据学习者选择的目标、投入和使用条件安排支持。指引说明学习目标如何逐步细化，日常教学判断的自主范围，以及涉及方向、显著投入和责任分配时怎样协商。

模型在辅导中如实解释表现及其依据，并将有后续价值的信息保存在记忆中。跨对话连续性由这些信息承接。

### 教学判断的共同依据

指引使用目标能力、当前状态与差距、活动与支持、表现证据之间的关系组织教学判断。有关概念的定义引用共同学习模型，具体安排参考辅导设计。

学习材料、任务、活动和支持分别说明其作用。模型结合当前需要选择讲解、示范、提问、尝试、练习、反馈和共同分析等安排，并依据实际回应调整。

### 记忆内容的含义与效力

指引说明如何分别对待学习者的选择与约定、自述、观察和模型推断。

- 选择与约定影响教学安排。
- 自述提供背景和初始理解。
- 观察保留实际表现及其条件。
- 推断说明当前认识、依据和适用范围，并可随新表现修订。

内容经由工具返回时，保持其原有含义。模型依据内容性质和适用范围使用它，并结合当前表现继续判断。

### 记忆的读取与更新

指引说明开始或继续学习时需要了解哪些已有信息，哪些新观察具有后续价值，以及怎样在阶段性停顿处更新进度、掌握判断和相关特征。

读取和更新围绕当前学习展开。目标或约定发生变化时，记录当前决定及有助于解释安排的信息；修改学习者设定遵循已经确定的确认要求。

工具的用途和职责见[服务端](server.md)，数据格式见[数据仓库](data-repo.md)。具体工具调用文字随相应规格确定。

### 学习方法的取用

方法参考为模型提供可复用知识，包括要解决的问题、适用条件、可选安排、取舍和可观察的效果。模型结合学习者的目标、状态和约定选用，并根据表现调整。

模型对某种做法形成的效果判断保留相应依据。学习者决定持续采用某种安排时，将其作为适用范围明确的约定处理。

## 设计文档与模型正文的分工

设计文档完整说明概念关系、理论依据、取舍和适用范围。模型正文按实际辅导需要组织相关内容，并通过参考文件补充说明。

设计内容可以采用定义、关系说明、例子或条件性方法等不同形式。正文的组织和篇幅以支持模型作出恰当判断为准。需要统一维护的定义由设计层负责，模型正文与其保持一致。

## 正文编写与验证

指引正文和方法参考根据共同学习模型、辅导与记忆设计编写。编写时核对以下关系：

- 目标、活动和表现证据相互对应。
- 学习者决定权与模型自主判断的范围清楚。
- 材料、任务、活动和支持的含义一致。
- 记忆中自述、观察、推断和约定的效力保持。
- 可选做法具有用途和适用条件。
- 工具使用与当前规格一致。

实际使用中，根据学习者表现、所需投入和使用体验修订内容。相关观察进入设计演进的依据，见[议题与决策](../decisions.md)。
