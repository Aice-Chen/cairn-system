# 数据仓库

本文说明数据仓库的目录结构和文件格式。数据仓库是记忆的实现形式；记忆的类别、效力、页面和更新方式见[记忆](../design/memory.md)。各部分的确认状态见[议题与决策](../decisions.md)。

## 与系统仓库的关系

Cairn 使用两个相互独立的 git 仓库。

| 仓库 | 内容 | 所有者 | 可见性 |
|---|---|---|---|
| 系统仓库 | 插件（技能、MCP 连接声明）、服务端源码、数据仓库模板、文档 | 项目 | 公开，不含任何个人数据 |
| 数据仓库 | 一位学习者的记忆 | 学习者 | 私有 |

数据仓库由系统仓库中的模板 `templates/data/` 建立。两个仓库之间没有合并关系：插件升级不改动数据仓库的内容，只有记忆格式变更时才需要迁移。

内容归入哪个仓库，取决于它对谁适用。对所有学习者适用的内容属于系统仓库，包括指引、学习方法和文档；只对一位学习者适用的内容属于数据仓库，包括这位学习者的设定、学习状态和学习记录。

## 目录结构

```text
<数据仓库>/
├── settings/               学习者设定
│   ├── general.md            通用设定，每次加载
│   ├── types/                类型设定，每种学习类型一页（可选）
│   └── projects/             项目设定，每个学习项目一页（可选）
├── state/                  学习状态
│   ├── progress/             学习进度，每个学习项目一页
│   ├── mastery/              掌握状态，页面的粒度和子目录由模型决定
│   └── traits/               学习特征
├── records/                学习记录，按日期归档，每天一个文件
├── sources/                学习材料，每个学习项目一个目录，不纳入 git
└── FORMAT_VERSION          记忆格式的版本号
```

有三点说明。

- 学习项目指一门课程、一本书、一个代码库或一个实践项目，对应 v1 中的“资源”。每个学习项目在 `state/progress/` 下有一个进度页，在 `sources/` 下有一个同名的材料目录。
- `settings/` 只包含学习者自己的陈述和约定。学习方法随插件提供，不在数据仓库中。笔记模板属于笔记生成模块，不在基础版的目录结构中，位置在该模块设计时确定。
- `state/` 按学习状态的种类分为三个子目录。`mastery/` 和 `traits/` 内部的页面划分不作规定。

## 记忆格式

本节规定页面、链接和学习记录的格式。其中与模型有关的部分，包括名称、链接和正文的约定，作为技能的参考文件 `memory-format.md` 提供给模型。

### 名称

页面以名称标识，名称即去掉 `.md` 的文件名。

- **学习项目**的名称由小写字母、数字和连字符组成，例如 `cs336`。它同时是该项目的进度页、材料目录和项目设定的名称。
- **学习类型**的名称为 `explanation`（讲解型）和 `practice`（实践型），用作类型设定的名称。
- **学习状态页面**的名称可以使用任何文字，包括中文、空格和括号，不超过 80 个字符，不含在文件名或链接中有特殊含义的字符：`/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|`、`#`、`^`、`[`、`]`。名称在 `state/` 内唯一，不区分大小写；子目录只用于归类。
- **设定页面**由级别和对象确定：通用设定为 `general`，类型设定和项目设定分别以学习类型和学习项目的名称命名。

### frontmatter

frontmatter 中只定义 `summary` 一个字段：必填，一行，不超过 200 个字符，概括页面的当前内容，新建和重写页面时提供。其他字段原样保留，服务端不作解释，例如 Obsidian 的 `tags`。

### 正文

服务端不检查正文的结构。正文的写法是对模型的约定，写在 `memory-format.md` 中，包括两项：

- 掌握状态中每项判断写明判断的内容、依据（包括观察时间）和确信程度；
- 进度页由基本信息、大纲或里程碑、当前位置、下次继续和说明组成。各学习方法对进度页的组织另有说明的，按学习方法。

### 链接

- 链接写作 `[[页面名]]`，与 Obsidian 的链接语法一致，指向学习状态页面。带显示文字的 `[[页面名|显示文字]]` 和指向标题的 `[[页面名#标题]]` 同样视为指向该页面。
- 代码块和行内代码中的内容不解析为链接。
- 链接可以指向尚不存在的页面。页面建立后，此前的学习记录中指向它的链接计入它的时间信息。

### 学习记录

学习记录的文件为 `records/YYYY-MM-DD.md`，每天一个，以一级标题写明日期。每条记录是一个列表项，依次为时间、学习项目、对话标记和内容：

```markdown
- 20:12 `cs336` `7f3k2a` 学习者要求先看公式，再看代码。
- 22:05 `-` `-` 学习者表示下周开始学习操作系统。
```

- 时间、学习项目和对话标记由服务端写入，位置固定；缺少的一项写作 `-`。内容可以跨行，后续各行缩进两个空格。
- 对话标记由 6 个小写字母和数字组成。服务端发放的标记原样写入；客户端或插件提供的对话标识，写入由它计算出的 6 个字符的摘要。由摘要不能还原原来的标识，原来的标识也不保存。
- 学习记录只追加。唯一的例外是页面重命名或合并时，服务端改写记录中指向该页面的链接；时间、学习项目、对话标记和其余的文字不变。

### 时间

时间信息不写入页面，由服务端计算。学习记录的日期和时间使用服务端配置的时区；数据仓库有多个副本时（见[插件](plugin.md)中“运行方式”），各副本的服务端使用同一时区。

## 示例

以下示例用于说明各类文件的样子，内容为虚构，具体格式以上文“记忆格式”为准。

通用设定 `settings/general.md`：

```markdown
---
summary: 通用设定：背景、总体目标和通用的辅导约定。
---

# 通用设定

## 关于我

有两年后端开发经验，熟悉 Python 和 Go。线性代数学过，不熟练。

## 目标

系统学习大语言模型的原理，能够独立实现一个小型的 Transformer 语言模型。

## 辅导约定

- 讲解新概念时，先给一个具体的例子，再给出定义。
- 推导类的内容先由我自己尝试，推进不下去时再提示。
- 我说“直接讲”时，直接给出结论和推导。
```

类型设定 `settings/types/practice.md`：

```markdown
---
summary: 实践型学习的约定：各部分由谁完成，无法推进时怎样提供支持。
---

# 实践型

- 与学习目标直接相关的代码由我自己写，环境配置和绘图可以交给模型。
- 无法推进时先指出方向，不直接给出写法。
- 作业先独立完成一版，再请模型查看。
```

掌握状态页面 `state/mastery/缩放点积注意力.md`，其中包含两项判断，各自写明依据和确信程度：

```markdown
---
summary: 能够说明缩放点积注意力的计算过程和缩放因子的作用；实现带掩码的版本时曾出现广播维度错误，尚未独立完成。
---

# 缩放点积注意力

所属学习项目：[[cs336]]。相关页面：[[多头注意力]]、[[因果掩码]]。

## 当前判断

**理解**：能够说明 Q、K、V 的含义和计算过程，能够解释除以 √d_k 的原因。
- 依据：2026-11-12 在没有提示的情况下完整解释；2026-11-14 讨论 [[多头注意力]] 时再次正确运用。
- 确信程度：较高。两次观察，间隔两天，情境不同。

**熟练**：能够在提示下完成实现，尚未独立完成。
- 依据：2026-11-14 实现时掩码的广播维度出错，经一次提示后自行改正。
- 确信程度：中等。只有一次观察。

## 后续可以验证的内容

- 独立实现带掩码的注意力，并通过课程作业中的测试。
- 说明注意力计算的时间和空间开销随序列长度的变化。
```

进度页 `state/progress/cs336.md`：

```markdown
---
summary: CS336 进行到作业 1 的注意力部分；讲座 1 至 3 已完成。
---

# cs336

## 基本信息

斯坦福大学 CS336（2026 年春季学期）。材料：`lectures/`、`assignment1-basics/`。

## 大纲

- 讲座 1 至 3：已完成。
- 作业 1：进行中。分词器已完成，注意力部分进行中。

## 当前位置

作业 1，注意力部分。[[缩放点积注意力]] 和 [[多头注意力]] 已讲解，带掩码的实现尚未独立完成。

## 下次继续

先独立实现带掩码的注意力，再进入 Transformer 块。
```

学习记录 `records/2026-11-14.md`，其中最后一条没有对话标记：

```markdown
# 2026-11-14

- 20:12 `cs336` `7f3k2a` 学习者要求先看公式，再看代码。
- 20:31 `cs336` `7f3k2a` 独立解释 [[缩放点积注意力]] 中缩放因子的作用，表述准确，没有提示。
- 20:58 `cs336` `7f3k2a` 实现 [[多头注意力]]：掩码的广播维度出错；在提示“检查掩码与注意力分数的形状”后自行改正。
- 21:20 `cs336` `7f3k2a` 学习者表示对拆分和合并注意力头的张量变形不熟练，希望增加练习。
- 22:40 `cs336` `-` 学习者表示明天先复习张量变形，再继续作业。
```

## 学习材料

学习材料放在 `sources/<学习项目>/` 下，只放模型可以直接读取的文件，项目内部可以自由建立子目录。材料由学习者放入，或由工具下载公开的文件。它不纳入 git，多台设备之间的同步使用 git 以外的方式。

一个学习项目使用哪些材料，写在它的进度页中，通常在基本信息部分。服务端在加载记忆时，报告材料目录中尚未写入进度页的新材料、修改时间晚于进度页的材料，以及写入了进度页而已不存在的路径。

学习者的作品，例如对一个主题的梳理成稿，也可以放在这里，模型像读取学习材料一样读取它。

## 格式版本

记忆格式的版本号记录在 `FORMAT_VERSION` 中。v1 的格式版本为 1，基础版为 2。服务端启动时检查版本号，与它支持的版本不一致时拒绝启动。格式变更时提高版本号，并在同一次变更中提供迁移说明或迁移脚本。基础版的数据仓库由模板新建，不提供从 v1 格式的迁移。

## 与 v1 数据目录的对应

下表供在 v1 服务端的基础上修改时参考，数据不作转换。

| v1 | 基础版 |
|---|---|
| `profile/` | `settings/` |
| `state/concepts.md` | `state/mastery/` 下的页面 |
| `state/progress/` | `state/progress/` |
| `state/log/` | `records/` |
| `sources/` | `sources/`，不变 |
