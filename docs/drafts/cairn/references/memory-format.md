# 记忆格式

本文件说明 Cairn 记忆的组织、命名与写入约定。内容的取舍及其效力按技能正文解释，服务调用的参数与返回以当前工具说明为准。

## 目录与内容

| 位置 | 内容 |
|---|---|
| `settings/general.md` | 学习者提供的背景、总体目标和跨项目协作约定 |
| `settings/projects/<项目>.md` | 该项目的目标、使用条件与持续协作约定 |
| `state/progress/<项目>.md` | 当前工作、实际进展和接续安排 |
| `state/mastery/` | 按概念、技能或主题组织的能力判断及依据 |
| `state/traits/` | 对后续辅导有帮助的个人特点与相关认识 |
| `records/YYYY-MM-DD.md` | 按日期追加的事件、观察和变更记录 |
| `sources/<项目>/` | 该项目的学习材料与作品 |

通用设定每次加载，项目设定在对应项目中加载全文。任务、情境和时间条件写在相应约定内；单个项目的持续要求放入项目设定，跨项目要求放入通用设定。

设定以学习者的陈述和选择为依据，模型判断进入状态。具体已选定的接续步骤与候选做法进入进度，并说明其实际状态；历史选择与变更进入记录。作品和材料全文保留在原载体，记忆引用与个人学习有关的内容。

## 名称与页面

学习项目名称由小写字母、数字和连字符组成，例如 `cs336`。该名称用于项目设定、进度页和材料目录。

学习状态页面以去掉 `.md` 的文件名作为名称，名称在整个 `state/` 内唯一，不区分大小写。名称可以使用中文、空格和括号，长度不超过 80 个字符；避开文件路径及链接中的特殊字符：`/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|`、`#`、`^`、`[`、`]`。子目录用于归类。通用设定页面名为 `general`，项目设定页面名为对应项目名称。

每个页面的 frontmatter 包含一行 `summary`，长度不超过 200 个字符。新建或整页重写时提供摘要，局部修改后摘要仍应准确反映当前内容。其他已有 frontmatter 字段原样保留。

页面正文使用自然段和有实际内容的标题组织。掌握判断写明能力及理解它所必需的依据和条件；进度写明当前位置与实际安排。页面大小取决于理解、引用和独立更新的需要。

以下示例展示一个有支持条件的观察怎样进入页面，内容为虚构：

```markdown
---
summary: 本次注意力实现中，在一次维度提示后自行定位并修正了转置错误。
---

# 注意力实现

2026-11-14，在 [[cs336]] 的注意力实现中，学习者得到检查最后两维的提示后，自行定位并修正了转置错误。
```

## 链接与依据

页面之间使用 `[[页面名]]` 关联学习状态，关系的含义写在所在语句中。`[[页面名|显示文字]]` 和 `[[页面名#标题]]` 同样指向该页面。代码块和行内代码中的文字作为示例或代码保留。

链接可以指向尚未建立的页面。页面建立后，已有记录中的相应引用会进入它的时间信息。创建页面仍取决于保存和使用需要。

判断的依据可以直接写在正文中，或关联到已有记录和相关页面。保留有助于后续理解的事件时间、任务和支持条件；事后报告说明由谁报告。

## 学习记录

由 `add_record_entry` 提交事件正文，服务端提供写入时间、项目和对话标记，并追加到当日文件。正文采用第三人称，直接观察、学习者陈述和模型当时的推断分别说明来源。

记录文件以日期为一级标题，每条为一个列表项，依次是时间、项目、对话标记和正文。例如：

```markdown
# 2026-11-14

- 20:58 `cs336` `7f3k2a` 学习者在一次维度检查提示后自行修正了 [[注意力实现]] 中的转置错误。
```

缺少的项目或对话标记写作 `-`。正文可以跨行，后续行缩进两个空格。对话标记由六个小写字母或数字组成，沿用工具返回值；客户端提供对话标识时由服务端处理。

记录采用追加方式保存，误记通过新的条目更正，并据此修订当前状态。页面重命名或合并时，使用相应工具维护已有链接。

## 时间与更新

服务端计算首次记录、最近涉及、涉及天数和页面最近更新等时间信息。页面正文只保留解释具体事件与判断需要的发生时间。记录的归档日期和写入时间使用服务端时区。

开始或继续项目时，通过 `start_session` 获取当前通用设定、项目设定、进度及相关信息。需要正文时用 `read_pages`，查找更多依据时使用索引、检索或关联读取。

新建学习状态页面使用 `write_page`。修改已有页面前，使用 `read_pages` 取得当前内容与版本，再通过 `write_page` 重写或 `edit_page` 局部修改，并带上读取所得的版本标识。版本发生变化时，基于最新内容整合本次变更。

设定通过 `update_settings` 保存。`confirmation` 说明学习者已经表达的陈述或选择及其范围，作为本次写入依据。沿用已有明确表达即可完成保存。

阶段性更新覆盖实际发生变化的内容。模型依据返回结果确认已保存的信息，供下次学习接续。
