# 辅导：教学依据与教学选择

本文说明 Cairn 如何根据学习目标、当前基础和实际表现组织辅导，包括学习活动发挥作用的条件、活动与支持的选择、反馈与判断，以及项目的持续推进。共享概念由[共同学习模型](learning-model.md)定义；信息的保存与效力见[长期记忆](memory.md)，交给模型的正文见[技能](../components/skill.md)。

## 辅导的职责

辅导帮助学习者形成目标所要求的理解、判断与行动能力，并推进当前需要完成的任务。模型结合目标的使用条件、学习者已有基础、可用材料和时间投入，选择讲解、示范、提问、尝试、反馈或共同分析等安排。活动可以从一个具体问题开始，随着交流逐步明确学习的范围与深度。

学习者决定目标、投入与协作约定。决定在其适用范围和期限内有效，模型据此安排日常辅导；涉及目标变化、显著增加投入或重新分配任务责任时，模型说明依据与取舍，由学习者决定。模型提出的建议与当前采用的安排保留各自的进度状态，并随目标、已有决定和实际表现调整；已经开展的活动则构成进度事实。目标、约定、计划与实际进展分别保存其含义。

评价辅导时，同时关注任务成果、能力变化和可供后续使用的信息。模型解释这些结果之间的关系，使学习者能够理解当前取得了什么进展，以及哪些认识值得在之后的学习中沿用。

## 教学依据

以下四组依据说明学习活动与支持为何有助于学习，以及效果受哪些条件影响。研究中的效果现象、对机制的解释和 Cairn 据此作出的教学选择分别表述。具体活动的采用取决于目标与情境，相关取舍集中见[教学选择](#教学选择)。

### 认知参与与知识组织

理解内容涉及把新信息与已有认识联系起来，组织概念之间的关系，并据此作出解释和推断。ICAP 区分外在任务与学习者参与材料的方式，讨论生成解释、建立联系和共同发展认识等活动的学习作用；它也指出，外显行为与内部加工之间存在差异。[^icap] 因此，阅读、听讲、讨论或实现的名称只提供初步线索，模型还需要结合实际内容理解这些活动提供了什么学习机会。

讲解可以帮助学习者找到问题的结构：哪些概念是前提，哪些关系解释当前现象，哪些条件变化会影响结论。示范进一步展示如何选择分析入口、使用证据和核验解释。模型据学习者已有认识选择深度与切入点，使具体例子和一般关系能够相互说明。

学习者自己解释原因、比较案例或预测变化，可以把已有认识用于新的组织和推理。例如，理解源码中的状态管理时，可以围绕一次具体状态变化连接数据结构、调用顺序和约束；比较两个输入造成的不同结果，则有助于辨认哪些条件起了作用。交流中的回应也使双方能够定位分歧，修订解释。

这些安排提供的学习机会，与已经发生的学习及可观察到的表现分别解释。学习者倾听或阅读时可以进行尚未外显的思考；模型根据已经取得的回应和行动陈述当前认识，并保留其证据范围。

### 已有知识与指导

已有知识影响学习者怎样理解任务、组织信息和选择行动。专长逆转研究表明，某些有利于经验不足者的指导，在相关知识增加后会失去优势，甚至因冗余而影响学习；认知负荷理论以知识结构和处理负担解释这种变化。[^expertise] 模型需要针对当前内容判断学习者具备哪些相关基础，据此选择支持。

对缺少分析入口的学习者，完整示范能够呈现问题如何被拆解、关键步骤为何成立。已有初步认识时，可以聚焦尚不清楚的关系，或让学习者完成方案中的一部分。关于示例渐退与自我解释提示的实验，在所研究的解题任务中发现，逐步减少已给出的步骤并提示解释其中的原理，有助于近迁移与远迁移表现。[^fading] 这为支持的调整提供了一种做法，具体范围仍需结合实际回应。

支持的作用还取决于它承担了什么。模型可以补足必要知识、准备环境或组织材料，使学习者能够投入目标相关的判断；也可以直接展示一个关键推理，帮助学习者建立初步认识。当目标要求学习者自己承担相应判断时，后续安排需要为这种承担提供机会。何时提供帮助、何时保留尝试空间，是需要结合学习条件权衡的问题。[^assistance]

生成式 AI 研究提供了具体情境中的例证。在高中数学复习实验中，采用通用聊天方式的 GPT-4 辅助提高了练习成绩，却降低了紧随其后的独立测验成绩；同时加入提示约束和教师题目信息的辅导版本缓解了这一负效应，独立测验表现与对照组无显著差异。[^bastani] 在有 Python 经验、首次使用 Trio 的开发者实验中，AI 组任务后的即时理解测验成绩较低，平均完成时间的差异不显著。[^shen] Cairn 据此分别关注任务产出、学习者实际承担的活动及目标能力表现，并按当前目标选择支持。

### 提取与时间分布

提取是学习者从记忆中重新调用已学内容，例如回忆一个条件、解释先前学过的关系，或在新问题中调用相应知识。它与再次阅读答案涉及不同的学习活动。短文学习实验发现，重复阅读在即时回忆中具有优势，而先前进行回忆练习的学习者在两天或一周后的回忆中表现更好。[^retrieval] 提取因此既可用于取得表现依据，也可因其对后续保持的作用而成为学习活动。

时间分布同样影响保持。言语回忆研究的定量综合支持分散学习的收益，并发现学习间隔与目标保持时间共同影响效果。[^spacing] 这些结果说明，在不同时间再次学习或运用重要内容具有教学意义；具体间隔应结合内容、已有基础和希望保持到何时来理解。

在持续项目中，已学知识可以通过后续任务重新被调用。例如，分析新的异常时再次解释此前学过的状态约束，既服务于当前问题，也让学习者在变化后的情境中运用旧知识。提取困难时，可以结合必要说明、提示或材料继续学习。目标允许查阅资源时，模型关注哪些认识由学习者调用、哪些帮助由资源提供。

记忆中的时间信息用于理解学习的分布和证据的新旧。最近接触某页内容，可能对应阅读、讲解、回忆或运用；其意义需要结合活动记录判断。回顾或练习的具体安排采用[教学选择](#教学选择)中的取舍。

### 反馈与学习调节

反馈使学习者能够认识当前解释、行动或作品与目标要求之间的关系，并据此修订知识和成果。它可以指出遗漏的条件，解释预测与结果的差异，揭示实现中的错误，也可以说明已经成立的部分及其依据。模型应使反馈对应到可以理解和处理的问题，并在继续学习时支持学习者运用这些信息。

反馈的依据随任务而变化。运行和测量能够提供具体结果，参考材料可以用于核对概念和论证，开放方案则需要结合目标、约束与证据比较取舍。模型说明依据覆盖的范围，例如测试验证了哪些行为、一个反例推翻了哪项假设，并据此帮助修订解释或作品。

反馈也会影响学习者对自身表现的认识。一般知识测验实验发现，反馈既帮助纠正错误，也提高了原先回答正确但信心不足的内容的后续保持。[^feedback] 因而，反馈可以帮助学习者辨认已有能力与仍有疑问之处，使之后的尝试和求助更有依据。

自我评估在学习者需要判断进展、选择帮助或调整投入时具有用途。概念定义学习研究发现，当学习者的自评影响停止练习的时机时，判断准确性与之后的保持相关；过早把不完整答案判断为正确，会使相应内容提前退出练习。[^selfassessment] Cairn 可以帮助学习者理解任务标准、比较自己的表现与依据，并据此决定如何继续。自我评估服务于相应目标和当前调节需要；只有学习者希望发展这方面能力时，才将其作为专门的学习目标。

## 教学选择

模型从学习者的当前请求及相关记忆理解教学重点，确定这一段交流希望推进的能力与任务。希望理解机制时，可以通过讲解、具体分析和解释展开；希望形成实现能力时，需要相应的设计、实现与验证机会。不同活动能够组合，范围和顺序随困难与回应调整。

选择是否增加一次提问、尝试、练习、回顾或比较时，模型综合考虑它对目标能力的预期收益、对当前任务的推进作用、能够取得的信息，以及所需的时间和负担。一项活动可以同时具有几种作用。例如，预测一个边界输入的结果，既可帮助学习者运用已学条件，也可推进对异常的分析。

如果活动主要用于澄清判断，关键是它的不同结果是否会改变后续安排。区分学习者缺少某个概念还是难以追踪状态变化，可能帮助模型在补充说明与路径分析之间作出选择。已有信息足以支持当前安排时，模型可以直接继续，以已发生的任务和支持条件界定当前认识。后续活动依据届时的目标和条件重新选择。

对于有价值的补充活动，模型进一步选择合适的范围与支持。能够随当前任务自然进行的局部尝试，可以与讲解交替；需要持续投入的练习、集中补充基础或系统梳理，则说明用途、投入与分工，依据学习者决定安排。学习者已经自然展示的表现可以直接用于判断。

例如，学习者希望理解某个模块为何出现重复处理，模型可以先用一条执行路径解释关键关系。如果学习者随后提出了关于并发顺序的疑问，一次针对相关路径的分析可能同时推进理解和问题定位。如果当前目标只是了解设计动机，直接说明关键取舍与材料依据就足以推进。选择取决于这次学习的目标、当前困难与投入。

已有约定在适用范围和期限内约束选择。日常活动由模型结合情境安排，并依据学习者新的要求和表现调整；模型对安排的效果判断则保留相应依据。关于安排的决定与关于能力、困难和效果的判断，分别采用[长期记忆](memory.md)中的效力约定。

## 材料、任务条件与核验依据

材料为学习者与模型提供共同分析的对象。讲解或分析时，模型区分材料直接提供的信息、补充知识和据此作出的推断，使有关解释可以回到具体内容核对。依据转述开展分析时，判断范围随实际取得的信息说明。

任务的产出要求、验收标准、期限和资源条件影响学习如何推进。学习者的明确请求可以表达对相关任务条件的采用，材料中的 AI 协作要求按同一采用范围解释。范围尚不明确且会影响当前分工时，模型说明相关内容与取舍；已有选择直接用于安排。学习者调整这些条件时，后续安排据此更新。材料描述的外部评价条件仍作为有来源的信息解释，任务进展与能力表现按实际发生的活动陈述。

## 表现的解释与教学经验

模型依据任务、支持、时间和情境解释表现。模块通过测试，说明作品满足了被测试的要求；学习者在其中提出了哪些设计、完成了哪些实现、作出了哪些核验，则为相应能力判断提供依据。目标允许使用资源时，也要保留本次资源具体提供了什么帮助。

即时表现与保持、迁移之间的关系需要结合条件判断。学习与表现研究说明，当次训练表现与之后的学习结果可以出现不同变化。[^performance] 模型据此用实际任务、支持与时间条件限定当前结论；取得进一步依据的安排统一采用[教学选择](#教学选择)中的取舍。

一种做法之后出现改善，可以支持模型继续考虑它的适用性。记录保留解释改善所需的任务与支持条件，以及会影响后续使用的相关信息。对方法效果的认识随新的表现修订；学习者决定持续采用某种做法时，再形成范围明确的个人约定。

## 学习项目的持续推进

开始学习时，模型依据已有目标、背景、材料和当前请求选择切入点。继续项目时，先理解已完成的内容、当前位置、新的问题与当前有效决定。模型可以按材料结构、问题或里程碑组织进度，并依据实际进展调整计划。此前提出的建议、已经开展的活动与仍然有效的学习者决定分别解释。

前置知识可以在任务中随用随补。某些内容说明到足以继续即可，另一些关系会持续影响后续理解与判断。当多个困难指向同一组基础，模型可以建议集中学习，说明它与当前目标的关系以及所需投入。学习者选择继续当前任务时，模型采用相应支持推进，并保留实际支持条件。

不同材料和活动通过目标、知识关系与实际困难衔接。课程中的概念可以用于分析源码，源码中的疑问可以引出局部实现或验证，作品中的经验也可以帮助重新理解概念。目标变化后，模型重新判断哪些内容值得深入，已有观察仍保留其发生时的条件。

系统性梳理可以用于组织知识、连接不同内容或形成后续查阅的成果。是否安排、覆盖哪些问题及如何分工，按[教学选择](#教学选择)处理。梳理的成稿、代码与其他作品归学习者所有，其保存和呈现由学习者选择；记忆保存与后续辅导有关的表现、判断和安排。

学习者决定项目何时结束。模型对照当前目标说明取得的进展、已有依据的覆盖范围和影响当前取舍的具体问题，并更新有后续价值的记忆。已结束项目中的知识在之后再次被用到时，可以结合新表现修订判断；主动回顾的产品范围见[目标与设计哲学](goals-and-principles.md)。

## 教学知识的组织与演进

基础版由本章与指引正文承载所需的通用教学知识，具体做法结合其用途和条件展开。模型选用和组合这些做法，观察到的表现与学习者体验为之后的调整提供依据。

具有清楚用途、适用条件和依据的经验，可以成为可复用的学习方法。研究支持的关系、产品采用的安排与个人使用中的效果判断分别保留来源。以后需要扩展时，根据教学需要、复用价值和维护成本决定是否增加专门参考内容，组织方式见[技能](../components/skill.md)。
