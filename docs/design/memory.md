# 长期记忆与学习状态

Cairn 的记忆保存理解学习者、延续学习和调整辅导所需的个人信息。它归学习者所有，以可阅读、可编辑的文本保存；更换对话、客户端或模型后，新的模型可以了解此前的目标、表现、判断和安排，并据此继续学习。

本文说明记忆内容的性质、效力及更新方式。能力、目标、学习活动与证据之间的关系见[学习模型](learning-model.md)。目录和格式见[数据仓库](../components/data-repo.md)，存取、加载和写入规则见[服务端](../components/server.md)，尚待细化的事项见[议题与决策](../decisions.md)。

## 内容的性质与效力

记忆按用途组织为学习者设定、学习状态和学习记录。设定保存学习者的背景陈述、目标选择和协作约定；状态提供当前学习的概况；记录保留具体发生的事情及其背景。一项内容的效力取决于它表达了什么、来自哪里，页面所在的位置只说明其组织用途。

| 内容性质 | 含义 | 在辅导中的作用 |
|---|---|---|
| 学习者的选择与约定 | 学习者决定的目标、约束、安排和持续适用的要求 | 在适用范围内作为行动依据，优先于系统的默认做法；由学习者决定是否调整 |
| 学习者的自述 | 对经历、基础、感受和表现的陈述 | 作为了解学习者的信息，保留陈述者、时间和语境，与后续表现共同解释 |
| 观察 | 在具体条件下可描述的行为、产出、反馈和事件 | 为判断提供依据，保留发生的条件及信息来源；记录可以由人核对和更正 |
| 模型推断 | 根据有限信息形成的能力判断、困难解释或教学效果判断 | 说明依据、适用范围和不确定性，随新的信息修订 |

例如，“我学过线性代数”是自述；“本项目先补线性代数”是选择；“在提示后正确完成矩阵求导”是观察；“遇到相近题目时仍需要提示”是对能力的推断。它们可以出现在同一页面，阅读和更新时仍分别处理。

学习者确认自己认同一项推断，可以成为理解其自我评价的补充信息；该推断仍需由相应证据支持。学习者决定以后采用某种做法，则形成一项协作约定。认同判断与选择做法分别保存，各自保留效力。

学习材料和学习作品可以与记忆一同保存和读取。记忆引用其中与个人学习有关的表现，材料的学科内容和作品全文由其原有载体承载。具体存放方式见[数据仓库](../components/data-repo.md)。

## 学习者设定与目标演变

学习者设定容纳背景、自述、目标和协作约定，以自然语言书写。模型依据背景和自述确定了解学习者的起点，依据明确的选择和约定开展辅导。某项水平自述与后续表现存在差异时，状态应说明观察到的范围和条件，自述保留其原有时间与含义。

约定按实际适用范围表达。通用约定适用于全部学习，项目约定适用于特定项目；某项要求还可以附带具体任务、情境或时间条件，例如“准备这次考试时，推导题先让我独立尝试”。范围更具体的明确约定用于对应情境，学习者后续明确作出的调整更新原有约定。不同范围的存储与加载映射在详细设计中确定，见[议题与决策](../decisions.md)。

目标可以从初始兴趣、现实任务或已有计划逐步形成。记忆保存当前希望获得的能力、使用情境、时间和资源约束，以及已达成的范围选择；尚待澄清的意图和模型提出的建议保留相应身份。目标的形成与调整见[学习模型](learning-model.md)及[目标、边界与设计哲学](goals-and-principles.md)。

目标或安排调整时，当前状态更新为新的方向，记录保留调整的原因及影响。原目标下形成的观察仍有其意义，模型根据新目标重新判断这些证据的相关性。项目暂缓或结束时，保存截至当时的进展、能力证据和遗留问题，供之后恢复学习或转向其他目标时参考。

模型可以起草设定、提出修改建议，并在学习者采纳后写入。学习者明确作出的持续性要求也可据此保存。观察到一种做法有助于当前任务时，先记录采用该做法前后的表现，再形成对其适用条件的判断；是否将它作为今后的固定约定，由学习者决定。

## 学习状态

学习状态概括当前的掌握情况、学习进度和学习特征，供后续辅导使用。其中既有观察的摘要，也有模型推断和后续安排，正文应让读者辨认三者的性质。

### 掌握状态

掌握状态描述学习者在什么条件下能够完成什么，以及证据尚未覆盖什么。判断围绕目标能力展开，说明任务或情境、完成方式、获得的帮助、表现发生的时间和推断的确信程度。表达采用可解释的能力描述，粒度随目标和证据确定。

同一项能力可以在不同条件下呈现不同表现。例如，学习者能够说明一段熟悉程序的机制，同时在陌生实现中定位同一机制仍需提示。状态应保留这一差异，并说明后续判断需要的证据。多次相近观察可以增强对相应条件下表现的把握，迁移到其他任务的范围仍由相关证据决定。

确信程度说明判断得到多少支持，以及不确定性具体来自哪里，例如观察次数有限、任务高度相似、关键步骤由模型完成，或尚未在间隔后再次观察。后续模型可以在适合当前目标的活动中验证这些判断，依据新表现补充、收窄或修订结论。

### 学习进度

学习进度保存项目当前的位置、已开展的活动、已完成的工作、未解决的问题和下次继续的内容。完成某项材料或任务作为进度事实记录；其中体现的能力另由掌握状态说明。

进度中的后续安排需要表达其依据和效力：学习者已选择的计划用于接续学习，模型提出的建议作为可调整的选项。安排随目标、可用时间和实际困难变化；改变安排时保留足够的背景，使后续模型能够理解取舍。

### 学习特征

学习特征保存有助于后续辅导的个人信息及判断，包括已有知识之间的联系、常用的类比来源、反复出现的困难、对不同支持方式的反应、自我评价与表现的关系，以及学习节奏。

特征以实际观察范围为边界。例如，“在本项目两次张量变形任务中，画出维度后自行发现了错误”支持对这些任务中该做法作用的判断。是否适用于其他内容，需要进一步观察。特征中保留情境、时间和例外，使模型能够根据当前表现调整理解。

## 学习记录与依据

学习记录保存有持续价值的事件，包括学习者的尝试、回答、错误、修正、所获支持、提出的要求，以及目标和安排的变动。记录描述发生的事情，涉及推断时标明其性质。

观察应包含足以理解表现的条件：学习者实际完成了哪些部分，材料、提示或模型承担了哪些部分，结果如何，以及观察来自当前对话还是学习者的事后陈述。对于事后提供的信息，记录“学习者报告了什么”，并在已知时说明事件发生的时间。写入时间用于归档，事件时间用于解释证据。

教学方式的作用通过具体反应记录。例如，说明采用某个类比后，学习者纠正了哪个错误、能否在新问题中运用该关系。对“这种方法有效”的判断放入状态，并保留对应条件和其他可能解释。这样的记录可以支持后续模型形成不同判断。

记录按日期归档，条目保持时间顺序，并带有所属项目及可选的对话标记。按日归档具有稳定的时间范围，也便于核对状态所引用的依据。记录采用追加方式保存；发现内容有误时补充更正，当前状态依据更正后的信息修订。页面重命名或合并时，服务端维护记录中的链接，具体规则见[数据仓库](../components/data-repo.md)。

## 页面组织与时间语境

页面是记忆的存取单位，一个页面可以包含多项判断，各项判断分别保留自己的依据和条件。页面可以围绕概念、技能或主题组织；合适的粒度应便于引用、独立更新和简要概括。内容变化时可以调整页面边界。

页面之间通过链接关联，关系的含义由所在语句说明。模型可以沿链接查看支持判断的记录和相关内容。索引提供页面概况，正文按需读取，使记忆增长后仍能围绕当前任务取用信息。页面格式、链接语法及索引生成方式见[数据仓库](../components/data-repo.md)和[服务端](../components/server.md)。

时间信息用于理解证据的新旧、学习的间隔和状态更新情况。首次记录、最近涉及、涉及天数和页面最近更新由服务端提供；具体判断的观察时间保留在其依据中。页面被再次提及，可能对应讲解、尝试、讨论或其他活动，模型需要结合记录判断它对当前能力提供了什么信息。

随着任务、目标和支持条件变化，旧判断的适用范围也需要重新解释。时间间隔可以成为再次观察的理由，具体选择哪项活动仍由当前学习目标和已有证据决定。

## 更新与跨对话延续

学习记录在出现有价值的观察时追加。学习状态在主题结束、学习自然停顿或学习者准备离开等阶段性时点更新，覆盖有新依据的掌握判断、学习特征，以及进度和接续安排。设定依照学习者的明确选择更新。更新集中于本阶段实际涉及的内容，原有依据和未解决的不确定性随判断一同保留。

学习可以在任意时点暂停，接续所需的信息因此随阶段性更新保存。系统以记录和状态的变化承载连续性，对话的开始和结束不作为更新前提。开始学习或间隔后继续时重新读取相关记忆，可以获得其他对话和学习者直接编辑带来的变化。阶段性更新前中止时，已追加的记录仍可供后续模型补充状态。

对话标记用于关联可能来自同一对话的记录，可缺失，其可靠性取决于来源。它作为检索线索使用，记录的归档和学习的继续均以现有内容为依据。标记的取得方式及跨对话写入协调见[服务端](../components/server.md)。

学习者可以直接阅读和编辑记忆页面。直接编辑作为新的信息进入后续辅导：目标和约定中的明确调整改变行动依据，对经历和能力的补充按自述理解，对原记录的纠正与对应依据一同核对。编辑后的内容仍按其来源和证据解释，保留观察与推断的性质。

基础版在内容再次涉及、出现新证据时修订相应状态。跨越多次对话的整体整理，以及对话之间的主动变更通知，保留为后续扩展；当前通过重新读取和局部更新维持状态，具体范围与重新考虑的条件见[议题与决策](../decisions.md)。
