# 长期记忆与学习状态

Cairn 的记忆保存理解学习者、延续学习和调整辅导所需的个人信息。记忆归学习者所有，以可阅读、可编辑的文本保存在其数据仓库中。更换对话、客户端或模型后，新的模型能够利用此前的目标、进展、判断及安排继续学习。

本文说明记忆的内容、效力、组织和更新。学习概念见[共同学习模型](learning-model.md)，文件与工具约定分别见[数据仓库](../components/data-repo.md)和[服务端](../components/server.md)，供模型使用的格式说明见[记忆格式草稿](../drafts/cairn/references/memory-format.md)。

## 保存什么，保存到什么程度

记忆保留对之后的学习有持续价值的信息，包括已经作出的选择、当前工作位置、具有解释价值的表现，以及由这些表现形成的判断。保存判断能够延续对学习者的理解，也使后续模型能够核对并修订它。

记录的详略与它对后续选择和解释的影响相称。简单的进展或局部观察可以用一句话表达；涉及长期约定、反复困难或重要能力判断时，保留足以理解来源、条件和依据的信息。需要达到的程度是：脱离原对话后，仍能准确理解内容当时所指，并判断它现在是否适用。

时间间隔、页面索引等可由现有数据可靠计算的信息，由服务端生成。能力、困难和方法效果需要解释，作为有依据的判断保存。相对于目标的差距可以进入当前状态，同时写明对应的目标与条件。

能力判断以已有依据覆盖的范围表达。一次表现可以支持一项有限的认识，尚未观察的其他情境保持在这个范围之外。是否增加活动由[教学选择](tutoring.md#教学选择)中的价值与投入关系决定；状态保存已经形成的认识和实际安排。

## 来源、范围与行动效力

写入、概括和读取时，都保持内容原有的来源、范围和效力。这项要求适用于被选择保留的正文、页面摘要与引用；压缩内容时优先保留会改变判断含义或安排依据的条件。当前状态的更新同时重新选择有持续用途的内容，以最新依据支持的认识重述其范围。

能力的边界通过实际任务、支持和时间条件说明。由未观察情境展开的待考察清单从当前状态与摘要中移除，与目标有关的具体差距则写明目标及其依据。模型的旧建议只有仍具接续价值时进入当前进度，历史记录继续保留实际发生的事件和选择。

学习者的选择决定目标、分工和协作方式；对经历、基础、感受和能力的自述提供个人信息。观察描述实际发生的回应、行动与结果，模型判断解释这些观察的意义。来源可以在自然语句中说明，例如“学习者表示”“本次实现中”或“根据两次表现判断”。同一页面可以容纳不同性质的内容，只要后续读者能够分辨。

学习者认同一项能力判断，为理解其自我评估提供信息；判断的成立仍依赖相应依据。学习者决定持续采用一种安排，则建立该范围内的协作约定。写入者可以是模型，决定者由实际交流确定。

### 学习者决定与模型安排

学习者的决定在其适用范围、期限和成立条件内作为行动依据。持续约定保留当前有效版本；一次性安排完成后成为已发生的进度。学习者表达新的选择时，相关设定或进度随之更新。

模型提出或采用的教学安排，供后续辅导接续和调整。进度如实说明已经开展的工作、当前选定的接续步骤和候选办法。后续模型依据当前目标、既有决定、实际进展和改变安排的成本选择是否继续。这里保存的是工作的状态与理由。

持续适用的协作约定在设定中维护；进度可以引用相关约定并说明据此采用的具体安排。记录保留决定或变更发生时的内容，供核对与恢复语境。持续约定的有效版本由设定提供，历史记述保留其时间范围。

### 材料与个人信息

学习材料和作品提供内容及表现依据。记忆保存其中与个人学习有关的事实与判断，材料原文、作品全文仍由各自载体承载。

材料中的任务要求、评价标准和协作建议保留其原有语境，学习者采用的部分成为当前任务条件。材料被读取或与记忆共同返回时，其来源保持清楚。任务条件的采用见[共同学习模型](learning-model.md#目标的形成与改变)。

## 内容组织与保存位置

设定承载学习者的背景、目标和持续约定，状态提供当前概况，记录保留事件及其语境。各位置具有默认用途，正文承担对具体信息性质的说明。

| 位置 | 保存内容 | 更新依据 |
|---|---|---|
| 通用设定 | 学习者提供的背景、总体方向、跨项目协作约定 | 学习者的陈述与明确选择 |
| 项目设定 | 该项目的目标、使用条件和持续协作约定 | 学习者对该项目的选择与调整 |
| 学习进度 | 当前工作、已取得的成果、实际困难及接续安排 | 项目中的事件、选择和教学安排 |
| 掌握状态与学习特征 | 对能力、困难和有助于辅导的个人特点的当前认识 | 相关观察、自述及其解释 |
| 学习记录 | 尝试、支持、结果、修正，以及选择和变更的历史 | 有后续价值的实际事件 |

### 设定与适用范围

通用设定每次加载，项目设定在相关项目中加载全文。任务、情境和时间条件写在对应约定中，由模型按内容判断适用性。适用于单个项目的约定放入该项目设定，跨项目约定放入通用设定。

学习者明确表达的持续性要求可以直接作为写入依据。模型起草的建议在学习者采用后写入设定，写入时保留实际选择的依据。明确选择已经存在时，使用该依据完成保存。

目标可以逐渐形成。已经明确的项目目标保存在项目设定中；模型为推进当前交流采用的暂时理解可以写在进度中，并保留其暂定性质。目标或约定发生变化时，更新当前有效内容，并记录有助于解释后续安排的原因与影响。

学习者的直接编辑同样按内容解释：对目标和约定的明确修改改变相应行动依据，对经历和能力的补充作为自述，对记录的更正与相关观察共同用于修订状态。

### 掌握状态与学习特征

掌握状态描述学习者在什么条件下能够完成什么。对判断有意义的依据包括学习者承担的部分、获得的帮助、表现结果、信息来源和观察时间。这些信息可以合并在自然语句中表达。

例如，“在一次维度检查提示后，自行定位并修正本次实现的转置错误”已经保留了观察的关键条件。如果进一步概括为跨任务的能力或困难，需要有相应范围的依据。判断的确信程度可以通过依据的数量、相似性、支持条件和解释局限说明；在这些差异影响使用时展开。

学习特征描述对后续辅导有帮助的个人特点，例如可用的先备知识、熟悉的类比来源、反复出现的困难和对某种支持的实际反应。范围依据观察确定，涉及方法效果时保留会影响后续使用的解释分歧。学习者选择将某种做法作为持续约定时，另行更新设定。

### 学习进度

进度让后续模型能够知道学习进行到哪里，以及接下来有哪些实际安排。它围绕项目需要组织材料、里程碑、当前位置、未解决的具体问题和接续内容；篇幅与项目规模相称。

完成某份材料或某个任务作为进度事实保存，其中体现的能力由相关掌握状态说明。进度摘要保留会影响接续的目标、位置和安排，重要的支持条件可以简要说明或链接到掌握状态。

接续内容根据实际发生的决定书写。学习者选择的下一步注明选择；模型当前采用的安排说明已有工作和选定的接续步骤；候选建议保留其可选性质。已有安排调整时，保存对理解变化有用的理由。

## 记录、摘要与时间

学习记录以第三人称描述有价值的事件，包括学习者的尝试、模型或材料提供的帮助、结果、修正以及目标和安排的变化。模型直接观察与学习者事后报告分别说明；已知的事件时间用于解释表现，写入时间由服务端提供。

记录按日期归档，条目依次追加。发现误记后追加更正，当前状态根据更正后的信息修订。历史判断也可以保留为当时的认识，当前状态采用相关的新依据。页面重命名或合并时，服务端维护记录中的链接，具体约定见[数据仓库](../components/data-repo.md)。

页面摘要用于索引和加载时的概览，应概括当前内容并保留影响解释的条件。正文中有条件的判断，在摘要中仍有相应范围；建议与学习者决定保持各自效力。多次概括或引用同一观察，其依据仍是原来的观察。

首次记录、最近涉及、涉及天数和页面最近更新由服务端计算。具体表现的发生时间写在相关依据中，两类时间分别服务于页面检索和证据解释。页面再次被提及可以对应阅读、讨论或实际运用，相关记录说明这次涉及包含了什么。

## 更新与跨对话延续

页面是记忆的存取单位，可以围绕概念、技能、主题或项目组织。粒度应便于独立理解、简要概括和局部更新，一个页面可以包含多项相关判断。页面之间通过链接关联，关系由所在语句说明。

开始或继续学习时，模型读取通用设定、当前项目设定和进度，依据摘要与近期记录选择相关页面。项目确定或切换后，加载相应项目的完整设定。需要理解某项判断或处理新旧信息差异时，再读取相关正文与记录。

新的有价值事件及时追加记录。在主题结束、自然停顿或准备离开等阶段，更新实际涉及的进度、能力判断和学习特征；设定依照学习者已经表达的选择更新。阶段性更新将已经形成的认识与安排交给后续对话，学习可以在任意时点暂停和继续。

模型写入状态前读取当前版本，结合其他对话或学习者编辑带来的变化更新内容。若中途暂停，已保存的记录仍可供后续模型补充状态。对话标记只提供关联线索，其可缺失性与具体取得方式见[服务端](../components/server.md)。

基础版通过重新读取、追加记录和局部更新维持连续性。跨多次对话的整体整理及对话之间的主动变更通知，作为有明确重新考虑条件的扩展事项保留在[议题与决策](../decisions.md)中。
