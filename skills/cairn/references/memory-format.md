# 记忆格式

本文说明记忆中各类页面和学习记录的写法。写入时遵守指引中“写入的规则”。

## 目录与名称

| 位置 | 内容 |
|---|---|
| `settings/general.md` | 通用设定 |
| `settings/projects/<学习项目>.md` | 项目设定 |
| `state/progress/<学习项目>.md` | 进度页，每个学习项目一页 |
| `state/mastery/` | 掌握状态页面 |
| `state/traits/` | 学习特征页面 |
| `records/YYYY-MM-DD.md` | 学习记录，由服务端写入 |
| `sources/<学习项目>/` | 学习材料 |

- **学习项目的名称**由小写字母、数字和连字符组成，例如 `cs336`。新建一个项目的进度页时，服务端同时建立同名的材料目录。
- **学习状态页面的名称**可以使用任何文字，不超过 80 个字符，不能包含以下字符：`/ \ : * ? " < > | # ^ [ ]`。名称在 `state/` 内唯一，不区分大小写。
- **设定页面**在工具中写作 `general` 或 `projects/<学习项目>`。

## 摘要

每个页面的 frontmatter 都有 `summary` 字段：一行，不超过 200 个字符，概括页面当前的内容。摘要是读取最多的文字，压缩时要保留判断的条件和内容的性质：建议仍写作建议，有条件的判断保留条件。

## 掌握状态

一个页面可以包含一项或多项判断。页面的粒度以三点为准：能用名称引用，能独立更新，能用一两句话概括。

每项判断写明三项内容：
- **能力的描述**：学习者能做到什么。
- **依据**：日期、任务、得到的支持，以及信息的来源，即这次对话中的观察，还是学习者事后的陈述。
- **确信程度**：在会影响理解或选择时写出，并说明不确定性的来源，例如只有一次观察、几次任务高度相似、关键步骤由你完成。

简单的判断一句话即可，例如：

> **实现**：带掩码的实现中，掩码的广播维度出错，在提示“检查掩码与注意力分数的形状”后自行修正。依据：2026-11-14，一次观察。

不列出尚未观察的方面。与目标有关的差距，写明对应的目标。

## 进度页

进度页由以下部分组成，可以依项目的性质，按材料的结构、里程碑或问题组织。
- **基本信息**：项目的来源和使用的材料。材料写出它在 `sources/<学习项目>/` 下的完整相对路径，例如 `week03/lecture-05.pdf`；整个文件夹写成以 `/` 结尾的路径，例如 `lab2/`。没有写出路径的材料，加载时会被报告为新材料。
- **大纲或里程碑**：各部分的状态。
- **当前位置**。
- **接续安排**：学习者决定的写作“学习者决定：……”；你的建议写作“建议：……”，并写明依据。
- **说明**：跳过的部分及其原因，尚未解决的问题。

完成某项材料或任务，是进度中的事实；其中体现的能力，写在掌握状态中。

## 学习特征

学习特征写学习者表现出的、较为稳定或跨内容适用的特征，并写明观察到的范围：哪些任务，什么时间，有无例外。例如：“在本项目两次张量变形的任务中，画出各维度后自行发现了错误。”

对教学方式效果的判断，同样写明条件。学习者决定今后持续采用的做法写入设定，不写在这里。

## 设定

设定只在学习者确认后写入。学习者对自己经历和水平的陈述，与学习者的约定分开书写。约定可以附带条件，例如“准备这次考试时，推导题先让我独立尝试”。

## 学习记录

学习记录用 `add_record_entry` 追加，只写内容；时间、学习项目和对话标记由服务端写入。

每条记录写明理解它所需的条件：学习者实际完成了哪些部分，提示、材料或你承担了哪些部分，结果如何。例如：

> 实现带掩码的 [[多头注意力]]：掩码的广播维度出错；提示“检查掩码与注意力分数的形状”后自行修正，测试通过。

学习者的决定作为事件记录，例如“学习者决定明天先复习张量变形”。记录有误时，追加一条更正，写明更正的是哪个时间的记录。

## 链接

- 链接写作 `[[页面名]]`，也可以写作 `[[页面名|显示文字]]` 或 `[[页面名#标题]]`。
- 链接指向学习状态页面，可以指向尚不存在的页面。
- 代码块和行内代码中的内容不解析为链接。
- 页面的时间信息由学习记录中指向它的链接计算，因此记录中涉及已有页面时，使用链接。
